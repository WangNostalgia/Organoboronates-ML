阶段一：准备与分配 (Data Preparation)

Data Preprocessing (数据预处理):
教授解析: 就像做反应前需要纯化试剂、重结晶一样，现实收集来的数据往往是"脏"的。这一步包括处理缺失值（删除全为空值的列），以及将数值特征筛选出来。本程序使用 MinMaxScaler 对特征和目标变量（活化能 activation_energy）进行缩放，将不同量纲的数据缩放到同一水平，避免某个数值过大的特征主导模型。

Split Data (数据划分 - Training Set / Test Set):
教授解析: 为了检验模型是否真的学到了规律，而不是在"死记硬背"，我们必须把数据拆分。训练集 (Training Set) 就像是你平时练习用的题库，模型在这里学习规律；测试集 (Test Set) 则是期末考试卷，在模型建好之前绝对不能让它看到，用来测试它的真实水平。本程序使用 80/20 比例划分 (random_state=42)。

阶段二：模型训练与超参数优化 (Model Training & Hyperparameter Optimization)

这个蓝色框是模型学习的过程。程序默认训练三种回归模型：SVR（支持向量回归）、RandomForest（随机森林）、KNR（K近邻回归）。

LOOCV (Leave-One-Out Cross Validation, 留一交叉验证):
教授解析: 假设你有 N 个样本。LOOCV 就是每次抽出 1 个样本作为验证，用剩下的 N-1 个样本训练模型，如此重复 N 次。这种方法在数据量较小（比如一些珍贵的实验数据）时非常有用，能最大程度地利用数据来评估模型的潜力。本程序在 Optuna 超参数优化的目标函数内部使用 LOOCV，以平均 MAE 作为优化目标。

Bayesian Optimization (贝叶斯优化):
教授解析: 机器学习模型有很多"旋钮"需要调，这被称为超参数 (Hyperparameters)（比如学习率、树的深度等）。贝叶斯优化是一种非常聪明的调参策略，它不像盲目尝试（网格搜索）那样浪费时间，而是会根据前几次调参的结果，预测哪组参数可能带来更好的效果。本程序使用 Optuna 框架的 TPESampler 进行贝叶斯优化，默认运行 100 次试验 (n_trials=100)。

Train Initial Model (训练初始模型):
使用上述优化好的超参数，在完整训练集上训练初始模型。

阶段三：初次评估 (Model Evaluation 1)

Evaluate Initial Model on Test Set (在测试集上评估):
教授解析: 拿我们一开始藏起来的"期末考试卷"（测试集）来考一考初始模型。如果它在训练集上表现极好，在测试集上却一塌糊涂，我们就说它过拟合 (Overfitting) 了——就像只背了题库但不懂举一反三。程序会输出 Train R² 和 Test R²，通过对比两者判断是否过拟合。

100 Random Splits Stability Test (100次随机划分稳定性测试):
教授解析: 为什么要在超参数优化后立即做100次随机划分评估？因为单次数据划分可能带来"运气成分"。使用不同的 random seed（0-99）重复训练和评估，计算平均 MAE，确保当前超参数组合的稳定性是可靠的。程序会将最佳 random state 和平均 MAE 记录在日志中。

阶段四：提炼精髓 — 迭代特征筛选 (Iterative Feature Selection)

现实中的数据往往包含许多特征（比如分子的各种理化性质）。有些特征是关键，有些则是毫无用处的噪音。这个蓝色框的核心目的就是"去伪存真"，并且是**迭代进行**的——每次移除最差的一个（或一组）特征后，重新训练模型、重新评估，直到满足停止条件。

SHAP Analysis (SHAP 分析):
教授解析: 机器学习常被称为"黑盒"。SHAP 是一种非常强大的解释性工具，它能告诉你每一个特征对最终预测结果做出了多少贡献（是正向促进还是反向抑制）。本程序根据模型类型自动选择最合适的 SHAP 解释器：树模型使用 TreeExplainer，线性模型使用 LinearExplainer，SVR/KNR 等使用 KernelExplainer（通过 K-means 聚类采样加速计算）。

Correlation Analysis (相关性分析):
教授解析: 检查特征与特征之间是否高度重合。如果两个特征总是同比例升降，它们提供的信息就是重复的，保留一个即可，这能减轻模型的运算负担。程序计算特征间的 Pearson 相关系数矩阵，以 0.8 为高相关阈值。

Importance Filtering (重要性过滤) & Iterative Filtering (迭代过滤):
教授解析: 基于前面 SHAP 和相关性分析的结果，每次迭代选择要移除的特征。选择策略分为两步：(1) 优先寻找相关性 > 0.8 的特征对，移除其中重要性较低的那个；(2) 如果没有高相关特征对，则移除重要性 < 20% 且重要性最低的特征。然后回到阶段二重新训练，如此反复，直到达到最小特征数 (min_features=5) 或无特征可移除为止。

阶段五：终极锻造与最终评估 (Final Build & Rigorous Testing)

Build Final Model with Selected Features (用筛选后的特征建立最终模型):
教授解析: 抛弃噪音后，用那些最纯粹、最关键的特征重新训练一个干净利落的最终模型。程序在迭代循环结束后，使用最终保留的特征集训练模型，并通过留一交叉验证 (LOO-CV) 评估其 R²_LOO。

Performance Tracking (性能追踪):
每次迭代的 MAE、R²、移除的特征、剩余特征数量都被记录在 performance_history CSV 文件和 PNG 图表中，方便回溯整个优化过程。最终模型、标准化器 (scaler)、特征列表、超参数和各项指标均保存为 .joblib 文件。

Final Visualization (最终可视化):
程序生成最终的实际值 vs 预测值散点图，标注训练集和测试集数据点，并自动识别偏差 ≥ 5.0 kcal/mol 的异常值导出为 CSV 文件。

阶段六：终极考验 (External Validation)

External Validation (外部验证):
教授解析: 即使你的模型在自己的测试集上表现完美，也可能只是在你的"小宇宙"里厉害。外部验证是指拿一批完全独立、来源不同的新数据来测试。这是证明模型具有真正泛化能力 (Generalization) 的金标准。本程序通过 example/prediction_round2.ipynb 笔记本实现外部验证，可使用 src/validation_process.py 生成完整的 sub_H × sub_B 组合验证空间。

Ensemble Prediction & Weighted Prediction (集成预测与加权预测):
教授解析: 俗话说"三个臭皮匠顶个诸葛亮"。集成预测不依赖单一模型，而是结合多个不同随机划分下训练出的模型结果。加权预测则是根据各个模型在测试集上的可靠程度（如 MSE 的倒数），给它们赋予不同的权重（更准的模型话语权更大），从而得出一个最稳妥、最精确的最终结论。这些功能在 example/prediction_round2.ipynb 笔记本中实现。
